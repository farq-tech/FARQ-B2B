# طلبات tokens — الخلفية الحية (M3)

ما أضفت أي token. هذي الطلبات للوكيل الأول (src/styles/tokens.css):

## 1. ظلال المضلعات لكل درجة — `--live-facet-1..5`
المرجع يثبّت خمس درجات لكل خلفية. حاليًا المكون يشتقها من `--live-base` بنسب قريبة (src/live-bg/engine.ts → `FACETS`)، والنتيجة قريبة لكنها مو مطابقة بالبكسل.

| token | light (`:root`) | deep (`[data-tone="deep"]`) | accent (`[data-tone="accent"]`) |
|---|---|---|---|
| `--live-facet-1` | #FFFFFF | #121212 | #3DDC97 |
| `--live-facet-2` | #FCFCFC | #141414 | #42DD9A |
| `--live-facet-3` | #FAFBFB | #161616 | #48DF9E |
| `--live-facet-4` | #F7F8F8 | #111111 | #3AD893 |
| `--live-facet-5` | #F4F6F6 | #181818 | #4DE0A1 |

إذا انضافت، أبدّل الاشتقاق بقراءتها مباشرة (تعديل سطرين).

## 2. (اختياري) لون نص الشارة الممتلئة — `--live-on-back`
شارة السعر الممتلئة بلون الرجوع: نصها أبيض في المرجع. في درجة accent لون الرجوع أبيض، فيصير النص أبيض على أبيض. المكون الحين يختار تلقائيًا `--color-text-primary` إذا كان لون الرجوع فاتح. لو تبون التحكم يدويًا: `--live-on-back` (light/deep: #FFFFFF، accent: #3A4047).
