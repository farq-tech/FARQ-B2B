# تحديث صفحة الهبوط للتوجه المؤسسي

- تغيّر الهيرو إلى «من هدفك، للجهة المناسبة» دون تغيير الاسم أو الهوية.
- دعم الرسالة التسويقية للشراء والتسويق والاستفسار والشراكات، مع التصريح بأن تجربة الأهداف قيد التطوير ودون إرسال فعلي.
- زر التجربة يصف الوظيفة الحالية بدقة: بحث الموردين؛ لم يتغير مساره أو محركه.
- النبضات في شبكة الخلفية تحمل «تسويق، تسعير، استفسار، عرض»، باستخدام صور Canvas مخزنة؛ لا رسم للنص في حلقة الحركة.
- أضيف ذكر الجهات الحكومية وشبه الحكومية وغير الربحية ومتطلبات اعتمادها.
- مثال مقارنة الأسعار الحالي باقٍ كمسار شراء توضيحي.

## التحقق
Typecheck وbuild ناجحان. Lint خرج بنجاح مع تحذيرات موجودة في ملفات أخرى. لم يجر تحقق بصري في المتصفح أو قياس أداء جديد بعد التعديل.
التعديل محلي على engineering/goals-phase0؛ لم يُدمج أو يُنشر.
