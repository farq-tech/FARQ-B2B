# بداية حسب هدف المستخدم

اختيار واضح في الهيرو: تسويق أو استفسار أو تسعير. لا نستنتج هدفًا من اسم المنتج وحده؛ المنتج نفسه قد يُباع أو يُشترى. قبل الاختيار يظهر «حدد هدفك وابدأ» وينتقل إلى الاختيار؛ بعده تتغير أزرار الهيرو والقائمة وأسفل الصفحة إلى «ابدأ تسويق» / «ابدأ استفسار» / «ابدأ تسعير» بحسب الاختيار المشترك.

التسعير يفتح تجربة البحث الحالية. الاستفسار يفتحها مع توضيح أن النتائج لا تثبت توفر المنتج أو استلام جواب. التسويق يفتح نص هدف محليًا ويعلن أن اكتشاف المشترين قيد التجهيز؛ لا يرسل طلبًا إلى بحث البائعين ولا يرسل رسائل. لا تخزين دائم للنص. هذه واجهة اختيار بداية فقط؛ لا تنفيذ لمحرك المرحلة 1.

Typecheck وbuild ناجحان، lint دون أخطاء مع تحذيرات. لم يُختبر بصريًا في المتصفح، ولم يُنشر.
