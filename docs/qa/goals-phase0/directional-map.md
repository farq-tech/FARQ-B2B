# الخريطة بحسب العلاقة التجارية

بحث الخريطة الموثق يمر من targetingClient.searchTargets إلى /_targeting/search ثم /search في الخدمة الحالية، وعند وجود objective يستدعي Directory.search نفسه المستخدم في تجربة الهبوط. يبقى بحث /search القديم دون objective كما هو.

الإحداثيات ومعرفات الجهات تقرأ من دليل Parquet الفعلي. نتائج المشترين احتمالات استخدام بحسب النشاط، وليست إثبات طلب شراء. تعرض أول عشر جهات مرتبة دون اختلاق جهات إضافية. تغيير الاتجاه يمسح النتائج والتحديد ويمنع جواب البحث السابق من الظهور. إرسال مسار المشترين مغلق.

أضيفت مداخل البائعين والمشترين لصفحة الأهداف والطلبات. السجل القديم يحتفظ بتسميته كطلبات شراء؛ لا تتحول بياناته إلى مبيعات بإعادة التسمية. صفحات المقارنة والترسية ما زالت تخص الشراء، وليست تنفيذًا كاملاً للمرحلة الأولى.

التحقق: أربعة اختبارات محرك ناجحة، Python compile ناجح، TypeScript والبناء ناجحان بعد تصحيح نوع دالة التنقل. lint دون أخطاء مع تحذيرات سابقة. تحقق الواجهة على متصفح الهاتف لم ينفذ بعد.
