# استكمال أرقام التواصل

المسار الحالي /search يمرر نتائج Directory إلى contact_lookup.enrich بالترتيب الأصلي. يبحث عن ثلاثة أرقام مفقودة كحد أقصى في الطلب، وليس عن آلاف الجهات. أصحاب رقم موجود لا تُستبدل أرقامهم. يستخدم Google Places Text Search (New)، مع حقول الهاتف والاسم والموقع والمصدر فقط.

رفض تطابق الاسم الجزئي أو فرع أبعد من 2 كم أو مصدر غير Google أو جهة مغلقة. الرقم المكتشف هاتف غير مؤكد الواتساب. لا إرسال ولا تسجيل جهات ولا تعديل قاعدة بيانات. لا حفظ دائم لنتائج Google.

لم يوجد GOOGLE_PLACES_API_KEY في خدمتي farq-pricing وfarq-targeting. لذلك الربط غير مفعّل فعليًا. يلزم مفتاح Places API (New) مقيد على الخادم في farq-targeting؛ لا يوضع في VITE ولا يرسل بالمحادثة. لم تُنشأ موارد سحابية أو حساب فوترة.

أربعة اختبارات منفصلة ناجحة: تطابق صحيح، رفض اسم مختلف، رفض فرع بعيد، رفض مصدر غير Google. Python compile وTypeScript والبناء ناجحة، lint دون أخطاء. الاختبارات تستخدم ردودًا مصطنعة معزولة؛ لم يختبر اتصال Google أو استرجاع رقم حقيقي. لا اعتماد جاهزية الجلب قبل اختبار فعلي بالمفتاح.

وثائق API: https://developers.google.com/maps/documentation/places/web-service/text-search
