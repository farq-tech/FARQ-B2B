## القواميس وإعادة الاستخدام

أعيد استخدام lib/city-districts.js وdata/districts/*.geojson من فرق بناء، مع source_codes ومعرفات الأحياء الحالية. مرجع الرياض يحتوي 187 حيًا. ملف README ينسب الحدود إلى MOMRAH؛ ترخيص إعادة التوزيع لم يؤكد، لذلك الاستخدام محلي ولا ندعي اكتمال مرجع المملكة. استيراد ست مدن متاحة لا يساوي تغطية المملكة. أسماء المدن المأخوذة من السجل SOURCE_ASSERTED، لا VERIFIED. الإحداثيات المطابقة للحدود INFERRED لأن موثوقية إحداثيات السجل لم تُراجع.

استُخدم line-intent-authority.bindLineToIntent وCPO الحالي لفهم نص النشاط. هذا لا يُثبت منتجًا للبيع ولا الطلب على منتج. لا Ontology أو matcher بديل. hierarchy الحالي CPO قطاع/عائلة/تصنيف/نية يخص المنتج؛ لا نخلطه بتصنيف النشاط الرسمي ISIC4 ولا نختلق معادلة بينهما. ربط ISIC4 يحتاج بيانات مرجعية مع ترخيص ومراجعة؛ غير منجز بعد.

المخطط schema.sql نموذج SQLite معزول، ليس migration جاهزًا للإنتاج. يتضمن الجداول المطلوبة ويفصل سجل المصدر عن الكيان والفرع، مع اشتراط دليلين مستقلين لدور BOTH. لا تعيين كيانات أو دمج آلي بالاسم/الهاتف. قبل التنفيذ الدائم يعاد استخدام construction.suppliers وsupplier_product_evidence وsupplier_profile_facts وsupplier_price_observations حيث تؤدي الوظيفة؛ لا نسخ بياناتها إلى مخزن موازٍ الآن.
