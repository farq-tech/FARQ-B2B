# أيقونات قنوات التسعير

استبدلت كلمتي «طلب» و«عرض» بأيقونات مرسومة فقط: واتساب ورسالة ومكالمة. زدت النبضات إلى موجتين متباعدتين، بحد أقصى 6 أيقونات في شاشة الكمبيوتر و4 في الجوال، مع تباعد 52px ومراعاة حدود الشاشة والعناصر الفعلية. أبقيت التركواز للذهاب والذهبي للرجوع.

الأيقونات مرسومة مرة في ست صور Canvas صغيرة بدقة 2x. أثناء الحركة تستخدم drawImage؛ الاختبار سجل صفر استدعاءات fillText. لا تحميل صور أو خطوط إضافية.

شاشة الدخول تستخدم نفس المصدر الآن؛ تولد `scripts/sync-gate-network.mjs` ملف `public/gate-network.js` من `src/live-bg/webMesh.ts` حتى تتطابق الأيقونات والعدد والحركة.

التحقق: typecheck وlint وbuild نجحت، مع تحذيرات البناء السابقة. على 1440 و390 تعمل الحركة وتبقى الشبكة ثابتة عند تقليل الحركة، بدون تجاوز أفقي أو أخطاء JavaScript أو مخالفات axe. اختبار مستقل لحالات الذهاب والرجوع أكد الحد الأقصى 6/4 وصفر نصوص. شاشة الدخول اجتازت الحركة وتقليلها دون أخطاء. إحصاءات الاختبار الوظيفي تشمل بداية التشغيل والتقاط Canvas؛ ليست قياس أداء معزولًا ولا تأكيدًا لحد الإطار القديم.
