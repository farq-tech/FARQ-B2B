# فرق أطلس

**الهدف:** بناء واجهة فرق الجديدة التي تجعل المستخدم يرى السوق، يحدد الجهات، يراجع اختياره، ثم ينشئ طلباً أو مسودة بإرادته ومن دون إرسال تلقائي.

**النطاق العام:** `atlas.farq.sa`

**نقطة الدخول:** تبقى الصفحة التعريفية العامة موجودة على النطاق الجديد، ثم ينتقل المستخدم إلى المنصة بعد تسجيل الدخول.

**مسار المستخدم:** هدف → بحث ونطاق → خريطة ونتائج متزامنة → اختيار جهات → مراجعة → طلب تسعير أو مسودة حملة → تأكيد إرسال منفصل.

**حالة التنفيذ:** تعمل خدمة `farq-atlas` على Railway. أُنشئ نطاق `atlas.farq.sa` وسجلّاه جاهزان للإضافة في DNS؛ ننتظر تحقق النطاق والشهادة.

**مبدأ الانتقال:** لا يُستبدل النظام القائم أو نطاقاته قبل مراجعة أطلس وربطه بالبيانات الفعلية والتحقق من المسار كاملاً.
