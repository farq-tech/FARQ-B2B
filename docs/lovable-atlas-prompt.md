# برومبت Lovable — تصميم «فرق أطلس»

> انسخ كل ما تحت هذا السطر والصقه في Lovable كما هو.

---

## من أنت وما المطلوب

أنت مصمّم منتجات ومهندس واجهات بمستوى عالمي. صمّم وابنِ تطبيق ويب متجاوباً (أولوية الجوال، ويعمل ممتازاً على سطح المكتب) اسمه **«فرق أطلس»**.

**لك حرية كاملة في الهوية البصرية والتخطيط والحركة والتفاعل.** لا تقلّد أي منتج موجود. ابتكر أسلوبك الخاص، واجعله يبدو منتجاً عالمياً فاخراً وهادئاً وموثوقاً، يليق بمحلّلين وأصحاب قرار. الشيء الوحيد غير القابل للتفاوض هو **القواعد** المكتوبة في هذا البرومبت (البيانات، الأرقام، اللغة، الخصوصية). كل ما عداها اجتهد فيه بذوقك.

---

## 1. المنتج بجملة واحدة

منصة خرائط وبيانات سوق للمملكة العربية السعودية، **تبدأ من خريطة واحدة وتنتهي بقرار**: أين تفتح فرعك، أين تسوّق، كيف توزّع، وبأي رقم تقارن.

## 2. المرتكزات الخمسة (لا تُكسر أبداً)

1. **الخريطة هي الانطلاقة.** لا صفحة «أدوات» منفصلة. كل قرار يبدأ بفعل على الخريطة: نقر حي، أو وضع دبوس، أو رسم نطاق، أو اختيار نشاط. الخريطة تملأ الشاشة، والباقي طبقات ولوحات فوقها.
2. **عدسة واحدة لكل فئة.** مبدّل واضح في أعلى الشاشة بين الفئات الخمس. العدسة تحدد ما تعرضه الخريطة واللوحة.
3. **كل رقم من البيانات أو «غير متاح».** لا تخمين، ولا تقدير ملفّق، ولا صفر مكان رقم ناقص. أي قيمة `null` أو مفقودة تُكتب حرفياً **«غير متاح»** بلون ثانوي هادئ.
4. **لا تصدير ولا تنزيل ولا طباعة.** لا أزرار CSV أو PDF أو «تحميل» أو «طباعة» في أي مكان. المشاركة تكون برابط عرض داخل المنصة فقط.
5. **لا إرسال آلي.** أي تواصل مع منشأة يكون يدوياً وبعد مراجعة المستخدم. لا تبنِ «إرسال جماعي» ولا «إرسال تلقائي».

## 3. قواعد العرض الثابتة

- **اللغة:** العربية فقط، واتجاه الصفحة من اليمين لليسار (`dir="rtl"`, `lang="ar"`). كل النصوص والقوائم والأيقونات الاتجاهية معكوسة بشكل صحيح.
- **الأرقام:** كل رقم في كل الشاشات بأرقام إنجليزية (0-9) وفواصل آلاف إنجليزية (مثل 118,800). **ممنوع** الأرقام الهندية (٠١٢٣) و**ممنوع** علامة «٪». علامة النسبة دائماً «%». استخدم دالة واحدة مركزية:
  ```ts
  export const numberFormat = new Intl.NumberFormat('en-US')
  // يحفظ الرقم أو النسبة أو التاريخ كاملاً داخل سطر عربي (عزل من اليسار لليمين)
  export const ltr = (t: string) => `⁦${t}⁩`
  export const percent = (v: number) => ltr(`${numberFormat.format(Math.round(v))}%`)
  export const show = (v: number | null | undefined, unit = '') =>
    v == null ? 'غير متاح' : `${ltr(numberFormat.format(Math.round(v)))}${unit}`
  ```
- **صيغ العدد العربية:** استخدم هذه الدالة لكل «عدد + اسم»:
  ```ts
  const NOUNS = {
    district: ['حي واحد', 'حيّان', 'أحياء', 'حياً', 'حي'],
    business: ['منشأة واحدة', 'منشأتان', 'منشآت', 'منشأة', 'منشأة'],
    branch:   ['فرع واحد', 'فرعان', 'فروع', 'فرعاً', 'فرع'],
  }
  export function counted(n: number, noun: keyof typeof NOUNS) {
    const [one, two, few, many, hundred] = NOUNS[noun]
    if (n === 1) return one
    if (n === 2) return two
    const size = Math.abs(n)
    const word = size >= 3 && size <= 10 ? few : size % 100 >= 11 ? many : hundred
    return `${ltr(numberFormat.format(n))} ${word}`
  }
  ```
- **المصدر:** لا يُذكر أي مصدر خارجي في الواجهة إطلاقاً، لا أسماء جهات حكومية ولا شركات ولا تطبيقات ولا خرائط. كل الأرقام تُعرض باسم **«فرق»** فقط (مثل: «دليل فرق»، «طبقة سكان فرق»، «طبقة مباني فرق»).
- **لا ملاحظات نصية طويلة تحت النتائج.** بدلاً منها: كل رقم قابل للنقر، فتظهر بطاقة صغيرة (popover) تشرح ببساطة **كيف حُسب**: تسمّي الطريقة لا المصدر، وتسمّي التقدير تقديراً. اجمع كل نصوص الشرح في ملف واحد `lib/explanations.ts`.
- **كل مؤشر مركّب يُعرض درجةً من 100 داخل مدينته** (مثل «72 من 100 داخل الرياض»)، ولا يُقارن أبداً بين مدينتين.
- **الشرائح العمرية** نمط تقديري للمنطقة لا قياس للحي. اعرضها بوصف «تقدير»، ولا تبنِ عليها فلتراً يفرّق بين الأحياء.

## 4. الهوية (نقطة انطلاق فقط، طوّرها بذوقك)

- اللون الأساسي لفرق: أخضر زيتوني داكن `#3E573B`، والنص عليه أبيض.
- لون إبراز من الشعار: أخضر زمردي `#00805F`.
- خلفية الشعار: رمادي فحمي `#303030`، والشعار حرف «F» أبيض مع كبسولة خضراء زمردية تحته على اليمين.
- اختر خطاً عربياً حديثاً واضحاً للأرقام والعناوين (مثل IBM Plex Sans Arabic أو Readex Pro أو Tajawal)، وتأكد أن الأرقام الإنجليزية فيه متناسقة ومتساوية العرض (tabular-nums) في الجداول.
- الوضع الفاتح والداكن كلاهما مطلوب.
- تلوين الخريطة: تدرّج تتابعي من خمس درجات (خُمسيات المدينة)، فاتح = أقل في المدينة، داكن = أعلى في المدينة، ورمادي شفاف = «غير متاح». أضف مفتاح ألوان (legend) صغيراً دائماً.

## 5. الفئات الخمس (العدسات)

كل عدسة رحلة بخطوات مرقّمة بترتيب القرار، ولها ثلاثة مقاييس تلوّن الخريطة (المحلّلون يرون كل المقاييس). البحث عن منشأة أو مورد ثابت أعلى الخريطة لكل الفئات.

### 5.1 أصحاب المتاجر
- **مَن:** صاحب منشأة أو سلسلة يدرس موقع فرع جديد. قراره مكلف، وخطؤه أكلف.
- **القرار:** «أين أفتح فرعي التالي، وبأي ثقة؟»
- **الخطوات:** أين ينقص نشاطي؟ ← المنافسون ← قارن المواقع ← محلات للإيجار.
- **الرحلة:**
  1. تُفتح الخريطة على مدينته وعدسة أصحاب المتاجر مفعّلة.
  2. يختار نشاطه، فتتلوّن الأحياء بطبقة **فرص التوسع**: سكان كثيرون ونشاط قليل.
  3. يضع **دبوساً** على موقع مرشّح، ويختار نطاق قيادة 5 أو 10 أو 15 دقيقة (أو دائرة بنصف قطر بديلاً).
  4. تظهر داخل النطاق ثلاث بطاقات: **السكان**، **المنافسون**، **درجة جاذبية الموقع**.
  5. يفعّل طبقات اختيارية: الدخل أو مستوى السكن، والبناء الجاري.
  6. ينقل الدبوس فتتحدّث الأرقام فوراً، ويقارن بين موقعين أو أكثر جنباً إلى جنب.
- **المقاييس الثلاثة:** ساكن لكل منشأة، السكان، المنشآت.
- **المؤشر البارز:** جاذبية الموقع، درجة من 100 داخل المدينة (سكان نطاق القيادة + القدرة الشرائية + كثافة المنافسين لكل كم²).
- **ثانوي:** نسبة السعوديين.
- **يُخفى:** تفاصيل المباني الفردية، المسارات، تقسيم المناطق.

### 5.2 المسوّقون
- **مَن:** مسوّق أو وكالة يوزّع ميزانية حملة. نوعان: **للمستهلك** (يهمّه الجمهور) و**للشركات** (تهمّه المنشآت القابلة للوصول).
- **القرار:** «أين أركّز ميزانيتي، وعلى مَن؟»
- **الخطوات:** أين جمهوري؟ ← منشآت الأحياء والحملة.
- **الرحلة:**
  1. تُفتح على طبقة كثافة السكان، ومعها شريط فلاتر.
  2. فلاتر المستهلك: الجنس، نسبة السعوديين، الدخل أو مستوى السكن.
  3. فلاتر الشركات: النشاط، والمنشآت التي لها واتساب.
  4. تتحوّل الخريطة إلى أفضل الأحياء مطابقةً.
  5. تظهر بطاقة **حجم الجمهور** في النطاق، وترتيب أعلى الأحياء.
- **المقاييس الثلاثة:** السكان لكل كم²، السكان، منشآت بواتساب.
- **المؤشر البارز:** كثافة الجمهور المستهدف، درجة من 100.
- **يُخفى:** تحليل المنافسين لكل موقع، النمو العمراني، المسارات.

### 5.3 الموزّعون
- **مَن:** مدير توزيع يغطي مدينته بمندوبين.
- **القرار:** «كيف أغطي مدينتي بكفاءة، وأين ينمو عملائي غداً؟»
- **الخطوات:** المناطق والمسار ← أين يُبنى الآن؟
- **الرحلة:**
  1. يختار نشاط عملائه فتظهر نقاطهم على الخريطة.
  2. يدخل عدد المندوبين ومعيار التوازن: السكان أو المنشآت أو زمن القيادة.
  3. تظهر مناطق متجاورة متوازنة، لكل مندوب منطقة بلون.
  4. يختار منطقة فيرى مسار الزيارة الأمثل: الترتيب والطول والزمن، بأي عدد من المحطات.
  5. يفعّل طبقة النمو فيرى الأحياء التي سيظهر فيها عملاء جدد.
- **المقاييس الثلاثة:** المنشآت، منشآت الجملة، منشآت بواتساب.
- **المؤشر البارز:** أولوية الحي للتوزيع، درجة من 100.
- **يُخفى:** الدخل والشرائح، واستهداف الجمهور الاستهلاكي.

### 5.4 المحلّلون
- **مَن:** محلّل في جهة حكومية أو استشارية أو تطوير عقاري.
- **القرار:** «أرقام موثوقة قابلة للمقارنة، فوراً.»
- **الخطوات:** الأحياء والترتيب ← قارن حيين.
- **الرحلة:**
  1. تُفتح الخريطة ومعها **جدول أحياء قابل للفرز** وبطاقات إجمالي المدينة.
  2. يختار مقياس الفرز فيتحدّث الجدول وتظليل الخريطة **معاً**.
  3. ينقر الأحياء فتظهر **مقارنتها جنباً إلى جنب**.
  4. يحفظ المقارنة داخل المنصة، ويشاركها **برابط عرض** لا بملف.
- **المقاييس:** كلها.
- **المؤشر البارز:** تشبّع النشاط = (منشآت النشاط ÷ سكان الحي) ÷ معدل المدينة. أكبر من 1 «مشبّع»، أقل من 1 «فرصة».
- **يُخفى:** توصيات بصيغة قرار جاهز، وأرقام التواصل الفردية.

### 5.5 الباحثون عن عقار
- **مَن:** فرد أو أسرة أو منشأة تبحث عن سكن أو محل أو مكتب للإيجار أو الشراء.
- **القرار:** «أي عرض يناسبني، وفي أي حي؟»
- **الخطوات:** اختر عقاراً ← تعرّف على الحي.
- **الرحلة:**
  1. يختار إيجاراً أو شراء، والنوع، والمدة كما يذكرها الإعلان، والميزانية.
  2. يرى العروض على الخريطة ملوّنة بسعرها **مقارنة بوسيط حيّها** (أرخص / قريب من الوسيط / أغلى)، ويفتح بطاقة العرض بصوره كلها.
  3. يضيف عرضين للمقارنة، فيسأله مساعد بسيط عن حاله (أسرة بأطفال، أعزب…) ثم يقارن من أرقام أطلس.
  4. يفتح الإعلان الأصلي ليتواصل مع المعلن من هناك.
- **المؤشر البارز:** السعر مقارنة بوسيط الحي.
- **يُخفى:** أرقام هواتف المعلنين لا تظهر أبداً.

### جدول منطق العدسة

| الفئة | الطبقة الافتراضية | الفعل الأساسي | البطاقة الأولى | المؤشر البارز |
| --- | --- | --- | --- | --- |
| أصحاب المتاجر | فرص التوسع | دبوس + نطاق قيادة | السكان داخل النطاق | جاذبية الموقع |
| المسوّقون | كثافة الجمهور | فلاتر الجمهور | حجم الجمهور | كثافة الجمهور المستهدف |
| الموزّعون | نقاط منشآت النشاط | تحديد المندوبين | منشآت كل منطقة | أولوية الحي |
| المحلّلون | تظليل حسب المقياس | فرز الجدول | إجمالي المدينة | التشبّع |
| الباحثون عن عقار | العروض ملوّنة بسعرها مقارنة بالحي | فلاتر العرض والمقارنة | بطاقة العرض | السعر مقارنة بوسيط الحي |

## 6. الشاشات والمكوّنات المطلوبة

1. **الخريطة الرئيسية (الشاشة الوحيدة الأساسية):**
   - خريطة بملء الشاشة (MapLibre GL JS بخريطة أساس مجانية بلا مفاتيح، مثل `https://tiles.openfreemap.org/styles/positron`) تعرض حدود الأحياء ملوّنة بمقياس العدسة.
   - **شريط علوي:** زر اختيار المدينة (بالاسم العربي)، وحقل البحث الثابت عن منشأة أو حي، ومبدّل العدسات الخمس (أيقونة + اسم، والعدسة النشطة واضحة).
   - **خطوات العدسة المرقّمة:** شريط صغير يبيّن رحلة العدسة (1 ← 2 ← 3) والخطوة الحالية.
   - **مبدّل المقياس:** المقاييس الثلاثة للعدسة بشكل segmented control، ومعه مفتاح الألوان.
   - **لوحة الملخص:** على الجوال bottom sheet قابلة للسحب بثلاثة ارتفاعات (مطوية، نصف، كاملة)، وعلى سطح المكتب لوحة جانبية على اليمين. حين لا يوجد تحديد تعرض ملخص المدينة، وحين يُنقر حي تعرض ملخصه.
   - النقر على حي يحدّده بإطار بارز، والنقر مع الاستمرار أو زر «أضف للمقارنة» يضيفه للمقارنة.
2. **بطاقة الحي:** عنوان باسم الحي، و**بطاقة الدرجة** في الأعلى (قيمة مقياس العدسة + «X من 100 داخل المدينة»)، ثم شبكة أرقام بطاقتين في كل صف: السكان، المنشآت، ساكن لكل منشأة، السكان لكل كم²، منشآت بواتساب، منشآت الجملة، ذكور · إناث (نسبتان)، السعوديون %، المساحة كم²، أكبر شريحة عمرية (تقدير)، ثم قائمة **أكبر الأنشطة في الحي** بأعدادها. كل رقم قابل للنقر لشرح طريقة حسابه.
3. **ترتيب الأحياء (للمحلّلين ومتاح للجميع):** جدول أو قائمة قابلة للفرز والبحث، مرتبطة بالخريطة (تحديد صف يحدّد الحي على الخريطة والعكس)، مع رتبة ورقم المقياس، وتبديل «الأعلى أولاً / الأقل أولاً».
4. **المقارنة:** من حيين إلى أربعة جنباً إلى جنب، مع إبراز الأعلى في كل صف بلطف. زر «حفظ المقارنة» وزر «نسخ رابط العرض».
5. **اختيار المدينة:** قائمة بحث بالمدن مرتبة من الأكبر، وبجانب كل مدينة عدد أحيائها بصيغة `counted(n, 'district')`.
6. **الدبوس ونطاق القيادة (أصحاب المتاجر):** دبوس قابل للسحب، واختيار 5 / 10 / 15 دقيقة أو دائرة، وثلاث بطاقات نتيجة. إن لم تتوفر بيانات النطاق في الواجهة، اعرض البطاقات بحالة «غير متاح» لا أرقاماً وهمية.
7. **فلاتر المسوّقين:** شريط فلاتر (الجنس، نسبة السعوديين، الدخل أو مستوى السكن، النشاط، لها واتساب) مع زر «إعادة ضبط».
8. **مناطق المندوبين (الموزّعون):** إدخال عدد المندوبين ومعيار التوازن، وعرض المناطق ملوّنة، وقائمة منشآت كل منطقة. إن لم يتوفر الحساب، صمّم الواجهة كاملة واعرض حالة «قريباً» بأناقة.
9. **العقار:** فلاتر (إيجار/شراء، النوع، المدة، الميزانية)، ونقاط العروض على الخريطة ملوّنة مقارنة بالوسيط، وبطاقة عرض بمعرض صور، ومقارنة عرضين.
10. **تسجيل الدخول:** شاشة بسيطة بالبريد وكلمة المرور (للميزات التي تحتاج حساباً لاحقاً مثل البحث عن منشأة وحفظ المقارنات). لا تنشئ نظام حسابات حقيقياً. اجعلها واجهة فقط قابلة للربط لاحقاً.

## 7. الحالات (صمّمها كلها، لا تترك أياً منها)

- **التحميل:** هياكل تحميل (skeleton) للوحة، ومؤشر خفيف فوق الخريطة «جارٍ تحميل الأحياء…».
- **الخطأ:** رسالة عربية واضحة («تعذر تحميل البيانات.») مع زر «إعادة المحاولة». لا تُظهر رسائل تقنية.
- **غير متاح:** القيمة الناقصة تُكتب «غير متاح» بلون ثانوي، والحي بلا بيانات يُلوَّن رمادياً شفافاً.
- **الفارغ:** بحث بلا نتائج («لا توجد نتائج لـ…») مع اقتراح.
- **بلا اتصال:** شريط علوي هادئ «لا يوجد اتصال».
- **عينة صغيرة:** أي رقم مبني على عدد قليل من العروض أو السجلات يحمل وسم «عينة صغيرة» صغيراً بلون تحذيري لطيف.

## 8. البيانات (حقيقية، للقراءة فقط)

القاعدة: `https://atlas.farq.sa/api/market/`. كل الطلبات للقراءة فقط ولا تحتاج مفاتيح.

> **مهم:** إن منع المتصفح الطلبات (CORS)، أنشئ طبقة بيانات `lib/atlas-api.ts` بواجهة واحدة، وشغّلها ببيانات تجريبية مطابقة **حرفياً** للأشكال أدناه (ضع ملفات JSON تجريبية في `mock/`)، مع متغيّر واحد للتبديل إلى الحي لاحقاً. لا تخترع حقولاً غير موجودة.

### 8.1 المدن
`GET cities` → مصفوفة، من الأكبر:
```json
[{ "en": "Riyadh", "ar": "الرياض", "n": 928941, "districts": 192 },
 { "en": "Jeddah", "ar": "جدة", "n": 409875, "districts": 189 },
 { "en": "Dammam", "ar": "الدمام", "n": 194330, "districts": 121 }]
```
اعرض فقط المدن التي `districts > 0`. الاسم المعروض `ar`، والمرسل للخادم `en`. `n` عدد المنشآت.

### 8.2 حدود الأحياء
`GET districts?city=Riyadh` → GeoJSON FeatureCollection (Polygon أو MultiPolygon):
```json
{ "type": "FeatureCollection", "features": [
  { "type": "Feature", "id": 353,
    "properties": { "ar": "نمار", "en": "Namar", "city_ar": "الرياض", "city_en": "Riyadh", "id": 353, "area_km2": 7.75 },
    "geometry": { "type": "Polygon", "coordinates": [[[46.705, 24.586], [46.704, 24.583], "..."]] } } ] }
```
اسم الحي المعروض `properties.ar`. **احمِ إطار الكاميرا من الحدود الشاذة:** احسب الإطار من الأحياء التي يبعد مركزها أقل من درجة واحدة عن وسيط مراكز المدينة (يوجد حي واحد على الأقل حدوده بعيدة خطأً).

### 8.3 أرقام كل حي (لتلوين الخريطة والجدول)
`POST district-counts` بجسم `{"city": "Riyadh"}` →
```json
{ "ok": true, "city": "Riyadh", "districts": [
  { "district_ar": "العليا", "n": 22483, "n_whatsapp": 1064, "n_wholesale": 1703,
    "area_km2": 9.447, "population": 118800, "residents_per": 5.28,
    "per_km2": 2379.78, "density": 12574.77 } ] }
```
الربط بالحدود عبر `district_ar` = `properties.ar`. المعاني:
- `n`: المنشآت.
- `n_whatsapp`: منشآت بواتساب.
- `n_wholesale`: منشآت الجملة.
- `population`: السكان.
- `residents_per`: ساكن لكل منشأة.
- `per_km2`: منشآت لكل كم².
- `density`: سكان لكل كم².
- `area_km2`: المساحة.

### 8.4 ملخص المدينة
`POST market-summary` بجسم `{"city": "Riyadh"}` →
```json
{ "ok": true, "summary": {
  "total": 927964, "districts_count": 252, "n_wholesale": 91358, "n_whatsapp": 56664, "n_specialties": 408,
  "top_districts": [{ "district_ar": "العليا", "n": 22483 }],
  "densest_street": { "street_ar": "شارع الأمير عبد المحسن بن عبد العزيز", "district_ar": "الملز", "n": 361, "length_m": 1555, "per_100m": 23.22, "sub_ar": "إنارة" },
  "main_activities": [{ "main_id": "food", "main_ar": "أغذية ومشروبات", "n": 152934 }] } }
```

### 8.5 ملف الحي (عند النقر)
`POST district-profile` بجسم `{"city": "Riyadh", "district": "نمار"}` →
```json
{ "ok": true, "city": "Riyadh", "district": "نمار",
  "population": 17500, "male": 10185, "female": 7315,
  "ages": [{ "age_group": "30-34", "age_code": "30", "male": 1400, "female": 823, "total": 2224 }],
  "saudi_pct": 58.7,
  "businesses": 1819, "whatsapp": 80, "wholesale": 114,
  "main_activities": [{ "main_id": "food", "main_ar": "أغذية ومشروبات", "n": 351 },
                      { "main_id": "fashion", "main_ar": "ملابس وأزياء ومجوهرات", "n": 94 }],
  "growth": { "district_ar": "نمار", "under_construction": 93, "new_buildings": 0, "homes_under_construction": 18, "floor_area_m2": 30396 },
  "income": null }
```
- `saudi_pct` و`income` و`growth` قد تكون `null` (الدخل متاح للرياض فقط)، فتُعرض «غير متاح».
- `growth`: «مبانٍ تحت الإنشاء» = `under_construction`، و«مبانٍ جديدة» = `new_buildings`.
- النسبة ذكور · إناث = `male/(male+female)` و`female/(male+female)` بصيغة `percent()`.
- `ages` نمط تقديري: اعرض أكبر شريحة بوسم «تقدير».

### 8.6 الدرجة من 100 داخل المدينة
للقيمة `v` بين قيم المدينة `values`: `score = 100 × (عدد القيم الأصغر من v) ÷ (عدد القيم − 1)`. والتلوين بالخُمسيات: قسّم قيم المدينة المرتبة إلى خمسة أجزاء متساوية العدد.

## 9. القياس الداخلي (لحظات القرار)

سجّل أحداثاً داخلية فقط (console أو endpoint داخلي وهمي)، **ولا ترسل بيانات المستخدم لأي طرف خارجي** (لا Google Analytics ولا غيره):

| الفئة | الحدث |
| --- | --- |
| أصحاب المتاجر | نقل الدبوس، ومقارنة درجتي موقعين (مع عدد المواقع) |
| المسوّقون | ضبط الفلاتر ورؤية الترتيب يتغيّر (مع الفلاتر المستخدمة) |
| الموزّعون | رؤية المناطق متوازنة، وحساب المسار (مع عدد المحطات) |
| المحلّلون | فرز الجدول وحفظ المقارنة (مع المقياس) |

## 10. ما لا تبنيه أبداً

- لا تخمين ولا أرقام وهمية في الواجهة الحية: الفجوة تظهر «غير متاح».
- لا توصية آلية بقرار نهائي («افتح هنا!»). اعرض الأرقام والدرجات، والقرار للمستخدم.
- لا أزرار تصدير أو تنزيل أو طباعة أو مشاركة ملفات.
- لا إرسال رسائل آلي أو جماعي.
- لا عرض لأرقام هواتف المنشآت أو المعلنين.
- لا ذكر لأي مصدر بيانات خارجي أو اسم شركة أخرى.
- لا أرقام هندية ولا «٪».

## 11. الجودة التقنية

- React + TypeScript + Tailwind، ومكوّنات shadcn/ui معدّلة لتناسب هويتك، وMapLibre GL JS للخريطة.
- هيكل واضح:
  - `lib/atlas-api.ts`: كل الطلبات وأنواعها.
  - `lib/format.ts`: `numberFormat` و`ltr` و`percent` و`show` و`counted`.
  - `lib/explanations.ts`: كل نصوص «كيف حُسب».
  - `lib/lenses.ts`: تعريف العدسات ومقاييسها وخطواتها.
- وصولية كاملة: تباين AA، تسميات عربية لكل زر وأيقونة، تنقّل بلوحة المفاتيح، أهداف لمس لا تقل عن 44px.
- أداء: تحميل حدود المدينة مرة واحدة وتخزينها مؤقتاً، وطلبات المدينة الثلاثة بالتوازي، وإلغاء الطلب السابق عند تغيير المدينة بسرعة.
- حركة ناعمة ومقتصدة (انتقال الكاميرا، فتح اللوحة، تبديل العدسة)، وتحترم `prefers-reduced-motion`.
- الصفحة الأولى تفتح مباشرة على خريطة الرياض بعدسة أصحاب المتاجر، بلا صفحة ترحيب ولا تسويق.
