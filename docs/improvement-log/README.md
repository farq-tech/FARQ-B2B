# سجل تحسين أطلس

كل تحسين في ملف مستقل، لا في ملف واحد مشترك. السبب: كل PR كان يضيف مدخله في أعلى `docs/opportunity-map-improvement-log.md`، فيتعارض مع كل PR آخر مفتوح بالتوازي. ملف جديد لكل مدخل لا يتعارض أبداً.

## الطريقة

- اسم الملف: `YYYY-MM-DD-وصف-قصير.md` بحروف إنجليزية صغيرة وشرطات، مثل `2026-11-03-log-per-entry.md`. الترتيب الزمني يأتي من الاسم.
- إن تكرر الاسم في اليوم نفسه، أضف كلمة تميّزه. لا تعدّل ملف مدخل غيرك.
- المحتوى بالصيغة نفسها:

```markdown
# 2026-11-03 — عنوان التحسين

- **الفجوة:** …
- **التغيير:** …
- **التحقق والحدود:** …
```

- المداخل حتى 2026-11-03 في الأرشيف `docs/opportunity-map-improvement-log.md`. لا تُضَف إليه مداخل جديدة.
