# Farq Atlas flat map symbols

This directory contains 51 standalone SVG symbols and transparent PNG exports at 1x and 2x (`@2x.png`), plus `map-ui-sprite.svg` with all symbols as SVG symbols. Files are designed for the Farq Atlas map and use the Atlas muted palette.

The set covers candidate-site pins and states, POI shells and variants, listing price pills, clusters, route depot and stops, search result pin, personal points, construction, status badges, unavailable-area hatching, route direction, and map controls. Activity artwork is supplied separately in `../icons/3d/`.

See `LICENSE.txt` for use terms. The companion `contact-sheet.png` and `map-markers-contact.png` are in the design delivery package.
