# فرق أطلس

واجهة أطلس المستوردة من النموذج المعتمد. وهي تطبيق مستقل عن تطبيق التسعير الحالي حتى تظل صفحة التسعير العامة وخدماتها مستقرة.

## التشغيل المحلي

```sh
cd apps/atlas
pnpm install
pnpm dev
```

لإظهار خريطة Mapbox الفعلية، عرّف `NEXT_PUBLIC_MAPBOX_TOKEN` محلياً أو في بيئة الاستضافة. لا يوضع المفتاح في Git.

## النشر

ينشر هذا المجلد كخدمة منفصلة ثم يُربط النطاق `atlas.farq.sa` بتلك الخدمة. يبقى ربط البيانات الفعلية والإرسال خارج هذا الاستيراد حتى تُراجع الواجهة المستوردة.
